# 安装手册

## 安装与更新

在运行 DSH Web 的机器上执行，路径换成实际的 `.tgz` 文件。

```sh
dsh plugin --profile web add /path/to/dsh-simplify-path-0.1.4.tgz
```

将 `web` 换成当前实例的 profile，沿用其 `DSH_HOME`，安装后重启该实例。与 `dsh-codex` 搭配时，将两个插件装到同一个 profile。

从源码安装时，在项目根目录执行以下命令，安装 `artifacts/` 下生成的包。

```sh
npm ci
npm run package:plugin
```

## 设置

在「插件 → 简化文件路径」中配置。

| 选项 | 默认 | 效果 |
| --- | --- | --- |
| 转换 WSL 盘符路径 | 开启 | 将项目和主目录之外的 `/mnt/c/...` 显示为 `C:/...`。 |
| Windows 盘符使用反斜杠 | 关闭 | 开启后显示为 `C:\...`。 |
| 允许复制简化路径 | 开启 | 在文件、目录和工作区菜单中提供「复制简化路径」。 |

## 使用

- 聊天链接 `./src/app.ts:42` 打开文件并跳到第 42 行。「复制简化路径」得到 `./src/app.ts`，DSH 自带的复制命令可获取绝对路径。
- 「环境」和 Files 中的工作区根目录显示为 `~/Projects/my-app` 或 `C:/Projects/my-app` 等可辨认的目录位置。
- 多文件变更卡片也会简化历史轮次中的路径。启用官方「变更请求与工作树」插件后，工作树审阅中的相对路径以 Git 检出根目录为基准。
- `dsh-codex` 的「N 个文件有改动」列表、差异标题、补丁图注和输入栏工作树路径也使用简化显示。

已在 DSH Web `0.2.3-alpha.2` 验证。
