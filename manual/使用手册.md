# DeepSeek Harness 路径简化

安装插件包后，DSH Web 会话会将项目内路径显示为 `./src/app.ts` 形式，将 Host 主目录显示为 `~`，并以 `C:/Users/me/report.txt` 形式显示 `/mnt/c/Users/me/report.txt`。

## 安装

在项目目录执行 `npm ci` 和 `npm run package:plugin`，然后安装生成的包。

```sh
dsh plugin --profile web add ./artifacts/dsh-simplify-path-0.1.2.tgz
```

使用自己的 profile 时，将命令中的 `web` 换成实际的 profile 名称。

## 设置与复制

在「插件 → 简化文件路径」中设置以下选项。

| 选项 | 默认状态 | 效果 |
| --- | --- | --- |
| 转换 WSL 盘符路径 | 开启 | 将项目和主目录之外的 `/mnt/c/...` 显示为 `C:/...`。 |
| Windows 盘符使用反斜杠 | 关闭 | 开启时，Windows 盘符路径显示为 `C:\...`。 |
| 允许复制简化路径 | 开启 | 在支持的文件、目录和工作区菜单中加入「复制简化路径」。 |

聊天链接可以显示为 `./src/app.ts:42`。点击会打开实际文件并跳到第 42 行。选择「复制简化路径」得到 `./src/app.ts`，需要绝对路径时使用 DSH 自带的复制路径命令。多文件变更卡片也用同一写法显示历史轮次的文件路径。

「环境」和 Files 用 `~/Projects/my-app` 或 `C:/Projects/my-app` 这样的目录标签标识工作区根目录。

启用 DSH 官方的「变更请求与工作树」插件后，Worktree 的检出目录提示和变更文件路径也可使用简化显示。工作树审阅中的相对路径以 Git 检出根目录为基准。

使用 `dsh-codex` 时，聊天历史里的「N 个文件有改动」列表、展开后的差异标题和输入栏工作树的路径标签也使用这些规则。使用同一个 DSH profile 安装两个插件即可。
